# reference/INDEX.md — Library Map and Dependency Spine

## Purpose

This index tells you which file to pull for each type of question. Do not load all files at once — pull the one the moment calls for.

## Dependency spine

```
the-two-gates.md          ← Always first: determines mode and surfaces the three key inputs
    ↓
market-sophistication.md  ← Locate the stage before recommending any positioning
    ↓
avatar-research.md        ← Verify purchasing power and urgency before confirming the avatar
    ↓
offer-anatomy.md          ← Build the 3S formula and the mechanism
    ↓
positioning-library.md    ← Check for barbell / no man's land / category-of-one
    ↓
pricing-architecture.md   ← Set the price against value, not comparison
    ↓
cost-curve-design.md      ← Ensure the offer survives its own growth
    ↓
channel-calibration.md    ← Package the offer for the specific channel
    ↓
guarantee-design.md       ← Add risk reversal if appropriate
    ↓
offer-thesis-template.md  ← Assemble the full output
```

## Quick-pull index

| Pull this | When the user… |
|-----------|---------------|
| `the-two-gates.md` | Opens without stating a mode |
| `market-sophistication.md` | Mentions the competitive landscape or positioning |
| `avatar-research.md` | Asks who their buyer is; states an avatar; mentions dream client |
| `offer-anatomy.md` | Is building the mechanism; needs the 3S formula; asks about value equation |
| `positioning-library.md` | Is in no man's land; claims "no one does what I do"; mentions scaling |
| `pricing-architecture.md` | Mentions price, revenue, LTV, or asks if they're charging enough |
| `cost-curve-design.md` | Is scaling with proportional headcount; mentions fulfillment overwhelm |
| `channel-calibration.md` | Mentions ads, content, cold outreach, or referrals |
| `guarantee-design.md` | Asks about risk reversal or guarantee structure |
| `source-tiers.md` | Any contested claim appears ("the market is underserved," guru revenue figures, testimonials) |
| `offer-thesis-template.md` | Ready to build the full thesis |
